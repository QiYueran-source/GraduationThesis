# model_config.config 字段与随机范围（cate=1/2）

主机端生成 `train_config.model_config` 时，根据 `cate` 在 `config` 中填入下列字段；若需随机采样，可参考下表范围。

---

## cate = 1（TCN）

| 字段 | 类型 | 必填 | 默认值 | 随机范围 / 建议 |
|------|------|------|--------|------------------|
| `num_channels` | `int[]` | 否 | `[64, 64]` | 每层通道数，列表长度 1～3；每项在 `[32, 128]` 内采样，如 `[64]`、`[64, 64]`、`[64, 128]` |
| `kernel_size` | `int` | 否 | `3` | 卷积核大小，取奇数：`3`、`5`、`7` 中采样或固定 `3` |

示例（随机）：

```json
{
  "num_channels": [64, 128],
  "kernel_size": 5
}
```

---

## cate = 2（LSTM）

| 字段 | 类型 | 必填 | 默认值 | 随机范围 / 建议 |
|------|------|------|--------|------------------|
| `hidden_size` | `int` | 否 | `64` | 隐藏维数，在 `[32, 128]` 或 `[64, 256]` 内采样 |
| `num_layers` | `int` | 否 | `1` | 层数，在 `[1, 3]` 内采样 |
| `bidirectional` | `bool` | 否 | `false` | 是否双向，在 `true` / `false` 中随机或固定 |

示例（随机）：

```json
{
  "hidden_size": 128,
  "num_layers": 2,
  "bidirectional": true
}
```

---

## 说明

- 所有字段均可省略，节点端使用上表默认值。
- 主机端按 `cate` 只生成对应模型的字段即可（cate=1 只填 TCN 字段，cate=2 只填 LSTM 字段）。
- 随机范围可根据实验需求收紧或放宽。
